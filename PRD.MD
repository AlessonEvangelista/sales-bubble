# Documento de Requisitos do Produto (PRD)

## Visão Geral do Projeto

O projeto é a evolução da compra coletiva, focado em um sistema de venda coletiva voltado para empresas. O sistema permite que usuários criem "bolhas" de pedidos, onde outros usuários podem participar adicionando produtos. Além disso, usuários podem indicar empresas que vendem peças ou produtos, e essas empresas podem dar lances para obter a venda.

Empresas também têm a possibilidade de criar bolhas de descontos em determinados produtos.

## Conceito do Sistema

O sistema abrange diferentes modelos de vendas: B2B, B2C, C2B, C2C. Usuários e empresas podem se registrar para criar bolhas de venda ou compra. Cada bolha funciona como uma compra coletiva, com um preço inicial e um preço de interesse como objetivo.

### Funcionalidades Principais

- **Criação de Bolhas:**
  - Usuários e empresas podem criar bolhas de venda ou compra.
  - As bolhas são visíveis a outros usuários de forma interativa, permitindo navegação e interação visual.

- **Participação em Bolhas:**
  - Empresas podem comprar várias cotas de bolhas.
  - Usuários podem comprar apenas uma cota por bolha.

- **Explosão de Bolhas:**
  - As bolhas têm um tempo pré-definido para "explodir", encerrando a participação e informando os envolvidos.

- **Triagem e Score:**
  - Após o encerramento, o sistema faz a ligação entre o criador da bolha e os compradores.
  - Existe uma triagem para verificar a conclusão da bolha, e o sistema mantém um score para os participantes baseado no cumprimento das etapas.

## Considerações Finais

O fechamento das bolhas e o processo transacional serão definidos com base em avaliações de mercado, podendo ocorrer dentro ou fora do sistema.

Este documento serve como uma base para o desenvolvimento e implementação do sistema, garantindo que todos os requisitos e conceitos principais sejam atendidos.
