# tools/

Scripts de apoio ao desenvolvimento e à operação (não são workspaces do npm):

- `ops/` — CLI de operação usada nos runbooks (`npm run ops -- <comando>`).
- `k6/` — testes de carga (`npm run test:load`).
- geradores e utilitários diversos.

Pasta criada vazia no BV-100; o conteúdo entra nas tarefas correspondentes
(ver [guia de desenvolvimento](../../002-llm/002%20Docs/06-engenharia/guia-desenvolvimento.md) §2 e §4).
